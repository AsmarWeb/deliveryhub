# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Security issues should be reported privately to the project maintainers.

When reporting a vulnerability, include:

- A description of the issue
- Steps to reproduce
- Potential impact
- Relevant logs or screenshots

Never include passwords, API keys, tokens, or other secrets in a security report.

## Supported Versions

Security fixes will initially target the latest development version of DeliveryHub.
